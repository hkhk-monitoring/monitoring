# Süsteemide monitooring

Server ei oska kurta. Ta näitab numbreid. Sellel kursusel õpid neid numbreid lugema, koguma, pildiks tegema ja nende peale reageerima, et saaksid probleemist teada enne kasutajat.

[Alusta kursusega](week07/lecture.md){ .btn-primary }
[Kursuse ülesehitus](syllabus.md){ .btn-secondary }
</div>
</div>

## Mida sa õpid

1. Lugeda käsurealt, kas server on terve: koormus, mälu, ketas
2. Panna masinad oma numbreid automaatselt koguma
3. Küsida andmetelt küsimusi ja teha neist töölaud, millest on kasu
4. Seada piirid, mille ületamisel saab inimene teada, ja õigel ajal
5. Lugeda ja otsida logisid ühest kohast, mitte igast masinast eraldi
6. Kontrollida väljastpoolt, kas teenus kasutaja jaoks üldse töötab
